# 算力资源看板

AI 卡算力资源看板的前端演示：按「三级部门 → 集群 → 卡」展示 GPU 利用率与调度率，包含资源总览、集群明细（NPU / GPU 分组）、训练任务统计和集群趋势四个模块。

- 单个 HTML 文件，图表使用 [d3.js](https://d3js.org/) v7.9.0（CDN 加载）
- 全局筛选：三级部门（ALL / 单个部门）、统计周期（周 / 月 / 年）
- 支持浅色 / 深色模式切换
- 数据为演示用的确定性随机数据

## 使用

直接用浏览器打开 `index.html`（需要联网加载 d3 和字体）。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 看板页面，包含样式、数据生成与渲染逻辑 |
| `UI设计文档.md` | UI 设计文档：信息架构、布局、视觉规范、各模块规格、交互与数据口径 |

接入真实数据时，替换 `index.html` 中的 `DEPTS_SPEC`（部门与集群清单）和 `dayVals` / `taskStats`（指标与任务数据）即可，渲染部分不需要改动。
